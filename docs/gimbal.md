# 二轴自稳云台开发记录

记录日期为 2026-11-20。

## 项目概况

项目基于现有 framework 框架，在 STM32F103C8T6 上运行
FreeRTOS，实现 yaw-pitch 二轴云台的姿态采集与控制。

当前阶段已完成定时采样、上电陀螺零偏校准、
四元数互补滤波、蓝牙遥测，以及舵机开环测试。
P 轴实测可从水平位置上抬约 84°。

## 硬件与接线

| 器件或功能 | 连接 |
|---|---|
| 主控 | STM32F103C8T6 |
| IMU | MPU6515，WHO_AM_I 实测为 0x74 |
| Pitch 舵机信号 | PA6，TIM3_CH1 |
| Yaw 舵机信号 | PA7，TIM3_CH2 |

| IMU SDA | PB7，I2C1_SDA |

| HC-05 RXD | PA2，USART2_TX |
| 电脑串口预留 | PA9/PA10，USART1 |
| 执行器供电 | 独立供电，与主控共地 |

## 构建与下载

在 Git Bash 中执行：

    cd /e/framework/port/stm32f1
    cmake --preset Debug
    cmake --build --preset Debug

生成文件为：

    port/stm32f1/build/Debug/f103_ref.elf

下载目标选择 STM32F103C8。

根目录的 F407 工程与 F103 子工程分别构建。
当前云台功能以 F103 子工程为准。

## 软件结构与运行方式

| 部分 | 当前作用 |

| module/attitude | 四元数互补滤波与 RPY 输出 |

当前 MPU6515 采样在 F103 板级代码中实现。
原 Mpu6050 设备类与 MPU6515 的统一封装待整理。

TIM2 每 10 ms 触发采样任务，名义采样频率为 100 Hz。
TIM4 用作 HAL 时基。
TIM3 的 PWM 帧周期为 20 ms。
蓝牙遥测由独立低优先级任务发送，采样与发送通过队列通信。

## 上电校准与姿态解算

陀螺量程设置为 ±250°/s，加速度量程设置为 ±2g。

上电静置采集 300 个连续有效样本，估计三轴陀螺零偏。
校准窗口包含角速度幅值、加速度模长和波动检查。
条件不满足或采样失败时重新收集窗口。

姿态采用四元数互补滤波。
陀螺积分预测姿态，加速度方向提供倾斜修正。
当前 correction_gain 为 2.0。
在线参数修改接口待实现。

Yaw 以姿态初始化时的方向为参考。
当前六轴 IMU 方案需要记录航向随时间的漂移。

## 坐标与机械范围

实测机械 Pitch 抬头主要对应传感器 Roll 增大。
机械 Yaw 左转对应姿态 Yaw 增大。

P 轴水平位置为机械下极限，记为 0°，
可从水平位置上抬约 84°。

水平位置对应的 Roll 零位需要在最终装配后重新采集。

### P 轴脉宽—角度标定表（重装前，历史）

标定条件：装配完成后单向扫描，每档停留 2 秒，
角度取该档内 IMU Roll 均值相对水平位的增量。

| 脉宽 (µs) | 抬升角度 (°) | 脉宽 (µs) | 抬升角度 (°) |
|---|---|---|---|
| 1500 | 0.0 | 2000 | +35.7 |
| 1600 | +0.6 | 2100 | +46.1 |
| 1700 | +9.6 | 2200 | +55.8 |
| 1800 | +17.8 | 2300 | +65.8 |
| 1900 | +27.5 | 2400 | +76.0 |
| | | 2500 | **+84.3** |

由该表得出：

- 有效增益约 **0.093 °/µs**（≈ 10.8 µs/度）
- 1500→1600 仅上升 0.6°，存在约 **100 µs 机械空程**
- 舵机死区约 **20 µs**，对应角度分辨率下限约 **1.9°**
- 2500 µs 为保守上限，此时抬升 84°；再往上接近舵机行程末端

### P 轴闭环基线（2026-11-23）

反馈量：`Roll − 水平采集零点`，单位度。零点由 `Z` 命令采集，
条件为平台位于机械止挡、P 轴脉宽等于 1500 µs。

控制周期 100 Hz；PWM 帧频率 50 Hz。

PI 参数：`Kp = 2 µs/°`、`Ki = 8 µs/(°·s)`，死区 `1.5°`。
输出范围 `1500～2100 µs`，每个采样周期变化不超过 `2 µs`。

已验收项目：

- 固定目标 `+20°` 保持，稳态误差在死区内，波动约 `±0.05°`
- 双向扰动恢复约 3～4 秒回到 `20°±3°`，无持续摆动
- 重复启停无突跳，重新接管时不跳变
- `P` / `Z` / `C` 命令互斥：运行中请求被拒，闭环继续
- `F`（撤销许可）、`T`（非法控制周期 30 ms）两种软件故障均能退出闭环并关闭 CH1
- 清除故障（`R`）只恢复许可，不自动重启；显式 `C` 可重新启动

故障注入入口由 `GIMBAL_ENABLE_FAULT_INJECTION` 控制，当前默认关闭（`0`）。
真实 I2C 总线故障尚未验收。

### Y 轴闭环基线（2026-11-23）

执行器为 SG90 180° 位置舵机，输出范围 `1440～1560 μs`
（实测 60 μs 阶跃对应约 4.94°，回位误差 0.03°）。

`H` 启动后先保持 `1500 μs` 预定位约 1 秒，待机械回位完成后再采集
航向参考并启用 PI。参考角若在舵机上电前采集，启动时的机械回位会被
当成误差，导致积分持续累积直到输出触限。

验收结果：

- 静置时脉宽固定在 `1500 μs`，反馈范围 `0.00～0.10°`
- 正向扰动 `+3.07°`、反向扰动 `−2.59°`，均在约 `0.1 s` 首次进入容差范围
- 后续 5 秒保持范围 `0.00～0.02°`，无摆动、未触限（脉宽 1480～1500）
- `X` 后 `enabled / state / ready = 0 / 0 / 0`、`CC2E = 0`，
  `yaw_pwm_updates` 在 2 秒内保持不变
- `yaw_pwm_errors = 0`，采样周期 `DT=10..10`、`MISS=0`

当前为短时相对航向保持。六轴姿态没有绝对航向参考，
长期漂移尚未验收。

工作软限位、上电轨迹和失联动作待结合标定结果实现。

## P 轴 0.8°死带基线（2026-11-25）

参数：目标20°，滤波K=2，Kp=2 us/deg，
Ki=8 us/(deg*s)，死带±0.8°。
闭环输出1500～2100 us，变化限速2 us/10 ms。

静置：最后30秒20.59～20.73°，均值20.66°，
脉宽1878 us不变，无持续修正。

正向扰动：基线20.64°，峰值22.52°，
回位后最低18.48°，最终19.41°。
反向扰动：基线20.00°，谷值18.02°，
回位后最高21.90°，最终20.73°。

两次最后30秒均持续处于19.2～20.8°，
无持续摆动、无触限、fault=0，恢复区间无缺帧。
X停止有效，DT=10..10 ms，MISS=0。
两次均未回到各自原基线±0.5°。

结论：保留0.8°死带作为后续基线。
手动松手时刻未同步标记；本轮未验收精确调节时间、
闭环带宽或指令阶跃性能。

### Kp单因素对比

保持Ki=8、死带±0.8°、滤波K=2及原输出限速。
Kp由2改为6，记录为p-step-kp6-01两份CSV，
本次零点18.425°，全程无人工碰触。

| 指标 | Kp=2 | Kp=6 |
|---|---:|---:|
| 上阶跃首次入±0.8° | 3.10s | 0.31s |
| 上阶跃持续入带 | 5.10s | 7.96s |
| 下阶跃首次入±0.8° | 4.65s | 4.41s |
| 下阶跃持续入带 | 11.00s | 6.76s |
| 25°段末5秒均值 | 24.73° | 24.68° |
| 返回20°后末5秒均值 | 20.47° | 20.49° |

持续入带要求此后到段末不再出带，且至少观察5秒。
Kp=6上阶跃首次入带后曾回落，不属于单调收敛。
两组均未连续保持在目标±0.25°内达到5秒。
无触限或轴故障，响应区间无缺帧，X停止正常。
保留Kp=6作为工作参数，尚未证明最优或达到动态指标。
