# STM32F407 三类运动识别

## 数据与输入

- 类别为静止、走路、跑步，编号依次为 0、1、2。
- MotionSense 标称 50 Hz，按受试者划分为 16 人训练、4 人验证、4 人测试。
- 每窗 100 点，步长 50 点。加速度和角速度各计算模长，再各取均值、
  标准差、最大值和相邻变化的平均绝对值，共 8 个模型输入。
- 板端 MPU6050 量程为 ±8 g / ±1000 °/s。标准化参数只用训练集计算。

## 模型与部署

- MLP 结构为 8 → 16 → 3，共 195 个参数，中间层使用 ReLU。
- 自写全连接算子使用 int8 权重和输入、int32 偏置和累加，
  以 Q31 整数乘数换算到输出刻度。每次推理用 16 B 暂存中间层输出。
- 串口 LIVE 输出时间戳、动作标签和三个 int8 分数。

## 实测结果

| 指标 | 结果 |
|---|---:|
| PC 浮点测试准确率 | 3386/3577（94.66%） |
| F407 定点回放准确率 | 3395/3577（94.91%） |
| 板端静止 / 走路 / 跑步识别率 | 2004/2006、953/1123、438/448 |
| PC / 板端标签一致率 | 3564/3577（99.64%） |
| 输出分数平均绝对误差 | 0.060765 |
| 单次推理最小 / 平均 / 最大时延 | 68.48 / 68.63 / 70.52 µs |
| 常规 Debug 固件 Flash / RAM / CCMRAM | 73524 / 22368 / 0 B |
| 模型参数数组 / 实时窗口 | 328 / 816 B |
| 遥测任务分配栈 / 实测峰值 | 2048 / 836 B |

时延以 168 MHz 固定输入测 200 次，仅计 infer()。
准确率来自 F407 回放 MotionSense 的留出窗口，右手腕现场准确率未测量。
任务栈峰值来自 70 次实时检查，窗口和预留栈不重复计入链接 RAM。

> 内存数据为最终固件（含 I2C 总线自恢复与栈水位观测）的链接结果；
> 早期 P5.2 在加入这两项之前的测量值为 Flash 73048 B / RAM 22360 B。

## 复现入口

依次运行 tools/ 下的 audit_motionsense.py、build_features.py、
train_float.py、quantize_int8.py、export_model_header.py、
export_preprocess.py 和 make_motion_smoke.py。
板端批量评估先运行 make_motion_replay.py，再以
`cmake --preset Debug -DMOTION_TEST_REPLAY=ON` 配置。
